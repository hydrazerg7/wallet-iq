# Photos

Drop your photos in this folder with these exact filenames. `index.html` already references
them; any that are missing are simply hidden on the page until you add them.

| Filename | Shot |
|---|---|
| `hero.jpg` | Right side, full bike (shown large at the top of the gallery) |
| `left.jpg` | Left side, full bike |
| `front.jpg` | Front three-quarter |
| `dash.jpg` | Dash lit up showing 4,618 miles |
| `exhaust.jpg` | Two Brothers Racing Black Series slip-on close-up |
| `rear.jpg` | Rear view: Yoshimura fender eliminator, LED signals |
| `wheel.jpg` | Rear wheel: Michelin Power 6, swingarm spool |
| `tank.jpg` | Brushed aluminum tank and carbon fairings |

Easiest way to upload: open the `photos` folder on GitHub → **Add file → Upload files** → drag
them in → **Commit changes**. Pages redeploys within a minute or two.

Tips: JPEG, long edge around 1600 px keeps the page fast. Crop the license plate out or blur it.
